## 📌 Overview

Road damage and potholes are major causes of accidents, traffic disruption, and infrastructure maintenance costs.  
This project provides an **automated computer vision solution** that detects potholes from road video footage and estimates the repair cost in real time.

The system combines:

- 🎥 Computer Vision
- 📊 Data Analysis
- 💰 Cost Prediction
- 🖥️ Interactive GUI
- 📤 Automated Reporting

to create a practical solution for smart infrastructure monitoring.

---

# ✨ Key Features

## 🔍 Real-Time Pothole Detection
- Detects potholes from uploaded road videos
- Uses OpenCV contour analysis and image processing
- Identifies potholes based on:
  - Shape
  - Size
  - Contours
  - Surface irregularities

---

## 📐 Dimension & Area Estimation
- Calculates approximate pothole dimensions
- Uses pixel-to-centimeter scaling
- Estimates affected road surface area accurately

---

## 💰 Repair Cost Estimation
- Predicts repair cost automatically
- Supports multiple road repair materials:
  - Asphalt
  - Concrete
- Generates estimated material expenses instantly

---

## 🖥️ Interactive GUI
Built using **Tkinter** for easy interaction.

### Features:
- Video upload support
- Result visualization
- Analytics display
- Simple user-friendly interface

---

## 📤 Excel Report Generation
- Automatically exports analysis reports
- Stores pothole statistics and repair costs
- Useful for:
  - Government agencies
  - Smart city projects
  - Road maintenance departments
